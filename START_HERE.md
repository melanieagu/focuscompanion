# Start here — Focus Companion

Your original blue screens and dinosaur images are included. This updated project adds shared pacts and a testnet contract. Keep your old folder as a backup.

## 1. Open this folder in VS Code

Open the folder containing `index.html` and `package.json`. Choose **Terminal → New Terminal**. Run each command separately:

```sh
npm install
npm run build
npm test
npm run test:ui
npm start
```

- Node.js 20 or newer is needed. If `npm: command not found` appears, install Node.js LTS from https://nodejs.org then completely reopen VS Code.
- `npm install` needs internet. Allow several minutes, and wait for it to finish.
- `npm run build` compiles the contract and installs the local browser wallet library.
- **Do not skip a failing test.** Send the full error back for a fix.
- `npm start` keeps running. Leave that terminal open and visit **http://localhost:3000** in Chrome.
- If you only want to explore the solo timer or Local preview first, `npm start` works without installing packages. Live wallet actions require the build.

## 2. Check the interface

Use the 10-second solo demo. Then click **Focus with a buddy → Local preview**, set 10 seconds, and create a preview. Click the explicitly labeled simulation buttons to explore both sides. **This preview makes no blockchain transactions and is not proof of the required integration.**

## 3. Get the actual blockchain integration running

You need a browser Ethereum wallet with **two accounts**, both holding free **Sepolia test ETH**. You can use a friend’s wallet as the buddy. Never share seed phrases or private keys. Never buy or send real ETH for this prototype.

1. Switch the wallet to **Ethereum Sepolia** before filling out the pact form.
2. In the app, select **Sepolia testnet** and click **Connect wallet**.
3. Expand **First time? Set up the testnet contract**.
4. Click **Deploy testnet contract**. Approve the deployment in your wallet and wait for the address to appear.
5. Copy that address into `config.js` as `contractAddress`, inside the quotes, and save. This ensures the published app points at your deployment.
6. Copy your second account’s public 0x address. From account 1, enter it as the buddy address, choose 10 seconds and 0.0001 test ETH, then create a pact.
7. Confirm the deposit transaction. Wait for its receipt, then copy the invite link.
8. Switch to account 2. The page reloads on account changes. Open the invite link if needed, click **Connect wallet**, then **Join & deposit**. Confirm its matching deposit.
9. Both accounts see the same onchain end time. Open the focus session, wait for the timer, and confirm completion from each account.
10. After both confirmations, **Claim my deposit** from each account. Claims are separate transactions. The explorer links are evidence of actual transactions.

Localhost links work on your laptop only. Publish before inviting someone on another device.
